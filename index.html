Connect to the question database to verify counts, inspect exact and near duplicates, edit a wrong question, and merge copies. Every merge and delete is checked inside Postgres — same chapter, one verified answer — and keeps an audit snapshot.

This page is public, the credentials are not. Anyone with the connection string can read and change the database, so use a Neon role limited to this database, disconnect when you finish, and never share a link containing it. Merges need the helper functions installed once (button above).
No database handy? Run the offline reviewer on your own machine instead: python -m review.dashboard --host 127.0.0.1 --port 8790 then open http://127.0.0.1:8790.
